## 🎬 OTT Trend Analysis with Python 🍿  
**Exploring 10,000+ Movie Ratings to Understand What Viewers Love!**

---

## 📌 About the Project

In this project, I analyzed **10,000+ IMDb movie ratings** from major OTT platforms like **Netflix, Prime, Hulu, and Disney+** using Python 🐍.  
I used **Exploratory Data Analysis (EDA)** to uncover what makes a movie popular and how trends differ across platforms! 📈📊

---

## 🧠 What We Did

✔️ Cleaned messy data  
✔️ Explored missing values and fixed them  
✔️ Visualized trends by platform, genre, ratings, and release years  
✔️ Compared platforms like Netflix vs. Prime based on user ratings  
✔️ Found cool insights about what OTT users prefer!

---

## 🔍 Key Tools & Libraries

- **Python** (Jupyter Notebook) 🐍  
- **Pandas** & **NumPy** – for data cleaning and manipulation  
- **Matplotlib** & **Seaborn** – for colorful and clear visualizations  
- **WordCloud** – to make our results pop! ☁️🎨
